## 💻 Sobre o Projeto

Este é o meu **1º projeto prático** focado em consolidar fundamentos de desenvolvimento web. A aplicação consiste em uma **Lista de Tarefas** interativa, simples e funcional, com foco em layout limpo e responsivo.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização, Flexbox, Layout Responsivo)
- **JavaScript** (Manipulação da DOM e lógica de adição/remoção de tarefas)
